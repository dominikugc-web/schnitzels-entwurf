# Schnitzel's Limburg, Website-Entwurf

Pitch-Entwurf für eine modernere Speisekarte von schnitzel-s.de, mit Bild zu jedem Gericht.

* `menu.js`: komplette Karte (Preise von schnitzel-s.de, Stand 17.11.2026)
* `img/`: KI-Symbolbilder, ein Bild pro Gericht. Echte Fotos einfach unter gleichem Dateinamen ersetzen.
* Seite ist per `noindex` von Suchmaschinen ausgeschlossen.
